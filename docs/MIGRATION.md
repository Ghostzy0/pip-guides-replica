# Move existing instructions into Guides

1. Keep an independent copy of your current instructions and images.
2. Create a new guide. Copy your own permitted title, descriptions and step order into its editor, or add images you have permission to use.
3. Review each picture; crop unnecessary areas and use solid redaction for private information.
4. Save/export a portable `.pipguide` file. Open it in another edition when transferring between the four separate app stores.
5. Export HTML or PDF and inspect the result before sharing. Existing exports are independent copies of earlier content.

There is no automatic import from proprietary Scribe/Tango projects, browser accounts or a team workspace. No account credentials are required. Keep old material until your saved and exported guide has been reopened and checked. Current experimental limits are in [verification](../PUBLIC-VERIFICATION.md).

Guides containing Tip, Alert or Header blocks use file format v2. Older v1-only builds refuse those files instead of silently converting the blocks into ordinary steps. Current builds still open older step-only v1 guides. Use a current build when moving typed guides between editions; keep the original file until the imported copy has been reviewed. A future unknown format or block type is preserved and refused rather than replaced with an older recovery copy.
