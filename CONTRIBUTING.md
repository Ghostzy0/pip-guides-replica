# Contributing

Use a focused issue and pull request. Describe the user-visible problem, reproduction, data/permission implications, exact checks and unverified native cases. Preserve the original baseline edition and the Pip edition build commands. Run `swift test` and build both app editions. Native capture changes need a selected synthetic surface, pause/stop race checks and permission-denied coverage. Never include personal guide files, credentials, screen recordings or competitor assets in commits.

Use licensed original work, retain notices and distinguish source checks from observed native behaviour. Report security-sensitive findings through the channels in SECURITY.md. Accessibility and multiple-display claims need real evidence. No paid CI usage is required; use local macOS checks until a free runner budget is confirmed.
